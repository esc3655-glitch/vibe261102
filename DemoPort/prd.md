# PRD: 개인 프로필 웹사이트 (DemoPort)

- 작성일: 2026-11-03
- 문서 상태: 초안 (v0.1)
- 연락처: esc3655@gmail.com

---

## 1. 개요

### 1.1 목적
사회복지·사업 기획 및 운영 분야 전문가로서의 경력, 역량, 프로젝트 성과를 한곳에 정리해 보여주는 개인 프로필(포트폴리오) 웹사이트를 만든다.

### 1.2 배경
- 이력서·경력기술서만으로는 사업의 기획 의도, 운영 과정, 사회적 성과를 충분히 전달하기 어렵다.
- 채용 담당자, 협력 기관, 후원·파트너 기업이 링크 하나로 전문성과 연락처를 확인할 수 있는 창구가 필요하다.

### 1.3 주요 분야
| 분야 | 설명 |
|---|---|
| 사회복지 | 복지 서비스 기획·제공, 사례관리, 지역사회 복지 네트워크 |
| 사업 기획 및 운영 | 신규 사업 발굴, 예산·일정 관리, 성과 측정 및 보고, 공모사업 수행 |

---

## 2. 목표 및 성공 지표

### 2.1 목표
1. 방문자가 30초 안에 "누구이며, 무엇을 잘하는가"를 이해한다.
2. 대표 프로젝트를 문제 → 실행 → 성과 흐름으로 보여준다.
3. 방문자가 이메일로 쉽게 연락할 수 있다.

### 2.2 성공 지표 (KPI)
- 이메일 문의 및 연락 전환 수
- 프로젝트 상세 페이지 조회 수
- 평균 체류 시간 1분 이상
- 모바일에서 Lighthouse 성능·접근성 점수 90점 이상

## 4. 기능 요구사항

### 4.1 페이지 구성 (원페이지 + 프로젝트 상세)

| 우선순위 | 섹션 | 내용 |
|---|---|---|
| P0 | Hero (메인) | 이름, 한 줄 소개(예: "사람과 지역을 잇는 사회복지·사회공헌 사업 기획자"), 연락하기 버튼 |
| P0 | About (소개) | 간단한 자기소개, 일하는 가치관, 핵심 키워드 |
| P0 | 전문 분야 | 사회복지 / 사회공헌 / 사업 기획·운영 3개 카드 |
| P0 | 경력 (Experience) | 기관명, 기간, 직무, 주요 업무 타임라인 |
| P0 | 프로젝트 (Portfolio) | 대표 사업 카드 목록 → 상세 보기 |
| P1 | 역량 (Skills) | 사업계획서 작성, 예산 관리, 성과평가(로직모델), 네트워크 구축, 홍보, 사용 도구 등 |
| P1 | 자격·교육 | 사회복지사 자격 등 자격증, 교육 이수 내역 |
| P0 | Contact (연락처) | 이메일 esc3655@gmail.com, mailto 링크, 이메일 복사 버튼 |
| P2 | 활동 소식 / 글 | 칼럼, 활동 후기, 언론 보도 |
| P2 | 이력서 다운로드 | PDF 이력서 다운로드 버튼 |

### 4.2 프로젝트 상세 페이지 구조
각 프로젝트는 다음 항목을 담는다.
1. 사업명 / 기간 / 역할 / 협력 기관
2. 배경 및 문제 정의 (어떤 사회적 문제가 있었나)
3. 목표 및 대상
4. 기획·실행 과정 (주요 활동, 내 역할)
5. 성과 (정량: 참여자 수, 예산 규모, 만족도 등 / 정성: 변화 사례)
6. 배운 점, 후속 과제
7. 사진·자료 (개인정보 비식별 처리 필수)

### 4.3 공통 기능
- 반응형 레이아웃 (모바일 우선)
- 상단 고정 내비게이션 및 섹션 앵커 이동
- 라이트/다크 모드 지원 (P2)
- 프로젝트 분야별 필터 (사회복지 / 사회공헌 / 기획·운영) (P1)
- SEO 메타 태그, Open Graph (링크 공유 시 미리보기)

## 6. 디자인 방향
- 톤: 따뜻하고 신뢰감 있는, 사람 중심
- 색상: 차분한 기본색 + 따뜻한 포인트 컬러 1개 (예: 그린/블루 계열 + 오렌지 포인트)
- 타이포그래피: 가독성 높은 한글 웹폰트 (예: Pretendard)
- 숫자로 보는 성과 영역을 강조 (예: "누적 참여자 ○○명", "운영 사업 ○건")
